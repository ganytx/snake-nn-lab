## 第 1 章 · 一个神经元是怎么算的

### 1.1 线性部分

最简单的模型：给一个输入 `x`，输出 `y = w·x + b`。

- `w` 叫**权重（weight）**，控制"这个输入有多重要"
- `b` 叫**偏置（bias）**，控制"默认倾向"

只有一个神经元时，它能表达的所有函数就是一条直线。这显然不够。

### 1.2 加上非线性：激活函数

把线性结果再喂给一个非线性函数 `f`：

```
z = w·x + b        ← 线性部分，叫【预激活值】或 logit
a = f(z)           ← 激活后的值
```

为什么必须加非线性？因为**线性函数的复合还是线性函数**。
`f(g(x))` 如果 `f`、`g` 都是线性的，合起来还是一条直线。
堆一百层也等价于一层。加了非线性，网络才能逼近任意复杂函数。

### 1.3 三个常用激活函数（`src/nn/activation.h`）

| 函数 | 表达式 | 值域 | 什么时候用 |
|------|--------|------|-----------|
| ReLU | `max(0, z)` | `[0, +∞)` | 深层网络的默认选择；正区间导数恒为 1，梯度不衰减 |
| tanh | `(e^z - e^-z)/(e^z + e^-z)` | `(-1, 1)` | 小网络、教学实验；零中心，比 sigmoid 好训 |
| sigmoid | `1/(1+e^-z)` | `(0, 1)` | 需要输出概率时（现代网络里基本只用在输出层） |

### ★ 1.4 一个必须记住的约定：导数的输入是 `z`

看你原来那份代码里的这两行：

```cpp
template <typename T> T dReLU(T x)   { return x > 0 ? T(1) : T(0); }   // x 是【激活前的 z】
double dsigmoid(double x)            { return x * (1.0 - x); }         // x 是【激活后的 a】
```

**两个导数函数对"输入是什么"的约定正好相反。**

- `dReLU` 要传 `z`：因为 `ReLU'(z) = (z>0)`
- `dsigmoid` 要传 `a`：因为 `σ'(z) = σ(z)·(1-σ(z)) = a(1-a)`

这不是写法问题，是**语义矛盾**。你想用一个 `dAF` 模板参数同时支持 ReLU 和 sigmoid，
是做不到的——不管怎么写，总有一边会用错。

**本项目的统一约定：所有 `d*` 函数的输入都是激活前的 `z`。**

```cpp
// src/nn/activation.h
inline double dsigmoid(double z) {
    const double s = sigmoid(z);   // 内部自己再算一次 σ(z)
    return s * (1.0 - s);
}
```

代价是 `dsigmoid` 多算一次 `exp()`，换来整个库接口一致、不可能用错。

> ⚠️ **如果误把激活后的 `a` 传给 `dAF`，程序不会报错，训练也不会崩，
> 只会"学得很差"——这是最难查的一类 bug。** 第 8 章的数值梯度检查就是为了
> 在出问题的时候能立刻定位到这里。

## 第 2 章 · 一层 = 一次矩阵乘法

一层里有很多神经元，每个都做一次 `z = w·x + b`。与其写循环，不如打包成矩阵。

### 2.1 行向量约定

本项目统一用**行向量**写法（和 `matrix.h` 的运算符方向一致）：

```
z = a_prev · W + b
```

含义：把上一层的输出 `a_prev` 看成 `1 × fan_in` 的行向量，
乘上权重矩阵 `W`（`fan_in × fan_out`），得到 `1 × fan_out` 的 `z`。

对应到 `matrix.h` 的运算符：

| 写法 | 含义 | `matrix.h` 里的重载 |
|------|------|---------------------|
| `M * v` | 矩阵作用在列向量上，(R×C)·(C) → (R) | `operator*(const matrix&, const vec&)` |
| `v * M` | 行向量左乘矩阵，vᵀ·M，(R)·(R×C) → (C) | `operator*(const vec&, const matrix&)` |

**神经网络用第二个。** 如果你习惯教科书里的 `W·x`（列向量），
那这里的 `W` 就是教科书的 `Wᵀ`——只是一次转置的区别，但必须全程一致，否则一定算错。

### 2.2 维度对照表（照着这张表检查代码就不会错）

以 `MLP<double, IN, OUT, NHID, HW>` 为例：

| 张量 | 形状 | 说明 |
|------|------|------|
| `a_in` | `IN` | 输入 |
| `w_in` | `IN × HW` | 输入 → 第 1 隐藏层 |
| `b_in` | `HW` | |
| `z_hid[0] = a_in * w_in + b_in` | `HW` | |
| `a_hid[0] = AF(z_hid[0])` | `HW` | |
| `w_hid[i]` | `HW × HW` | 第 i → i+1 隐藏层，共 `NHID-1` 个 |
| `z_hid[i] = a_hid[i-1] * w_hid[i-1] + b_hid[i-1]` | `HW` | |
| `w_out` | `HW × OUT` | 最后一个隐藏层 → 输出 |
| `z_out = a_hid[last] * w_out + b_out` | `OUT` | 输出 logits，**线性，不加激活** |

### 2.3 为什么输出层不加激活？

因为同一套网络要能同时干两种活：

- 接 **MSE** → 做回归（输出可以是任意实数）
- 接 **softmax + 交叉熵** → 做多分类 / 强化学习的策略（输出是未归一化的分数）

激活函数是"外面"的事，网络本身保持通用。这个设计在后面写 REINFORCE 时会体现出价值。

## 第 3 章 · 前向传播（以及为什么必须缓存）

### 3.1 代码

```cpp
// src/nn/network.h
const vec<T, OUT>& forward(const vec<T, IN>& x) {
    a_in = x;                                        // ★ 缓存输入
    z_hid[0] = x * w_in + b_in;                      // ★ 缓存 z
    a_hid[0] = apply(AF, z_hid[0]);                  // ★ 缓存 a
    for (int i = 1; i < NHID; ++i) {
        z_hid[i] = a_hid[i - 1] * w_hid[i - 1] + b_hid[i - 1];
        a_hid[i] = apply(AF, z_hid[i]);
    }
    z_out = a_hid[NHID - 1] * w_out + b_out;
    return z_out;
}
```

### ★ 3.2 你原来的写法错在哪

你原来的 `forward()` 是这样的：

```cpp
void forward() {
    vec<T, m> v = apply<T,m>(AF, in * w_st + b_st);
    for (int i = 1; n > i; i++)
        v = apply<T,m>(AF, v * w[i] + b[i]);
    out = apply<T,output_siz>(AF, v * w_ed + b_ed);
}
```

这是**纯推理**的写法：算完一层，`v` 就被下一层覆盖了，前面所有中间结果全丢了。

而反向传播需要用到每一层的：

- `z`（激活前的值）→ 用来算激活函数的导数 `dAF(z)`
- `a`（激活后的值）→ 用来算权重的梯度 `dW = a_prev ⊗ delta`

**所以 `forward()` 必须把 `z` 和 `a` 存下来。** 这就是从"会推理"跨到"会学习"的分水岭：
推理是流式的，训练是**必须回头看的**。

> 内存代价：`NHID` 个长度为 `HW` 的向量 × 2。对几千个参数的小网络完全可以忽略。

## 第 4 章 · 损失函数

损失（loss）是一个**标量**，衡量"网络现在的输出离正确答案有多远"。
训练的目标就是把这个数变小。

### 4.1 均方误差 MSE（`loss.h`）

```
L = (1/N) · Σ (y_i - t_i)²
∂L/∂y_i = 2(y_i - t_i)/N
```

适合回归问题。注意除以 `N` 是**平均**而不是求和——这一步会影响梯度的量级，
进而影响你能用多大的学习率。

### 4.2 softmax：把任意实数变成概率

```
p_i = e^(z_i) / Σ_j e^(z_j)
```

**数值稳定技巧（必学）**：先减掉最大值再取指数。

```cpp
T mx = z.a[0];
for (int i = 1; i < N; ++i) if (z.a[i] > mx) mx = z.a[i];
p.a[i] = std::exp(z.a[i] - mx);
```

因为 `e^z` 在 `z ≈ 800` 时就会溢出成 `inf`。减掉 max 之后最大的指数变成 `e^0 = 1`，
其余 ≤ 1，永不溢出；而数学结果完全不变（分子分母同乘 `e^(-max)`）。

### 4.3 交叉熵

```
L = -log( p[action] )
```

直觉：给"正确答案"分配的概率越接近 1，损失越接近 0；越接近 0，损失越大（`-log(0) → +∞`）。
这就是"让网络对正确动作越来越自信"的数学表达。

### ★ 4.4 一个必须记住的化简：`∂L/∂z = p - onehot`

如果老老实实按链式法则算 softmax + 交叉熵的梯度，需要先求 `∂L/∂p`，
再求 softmax 的**雅可比矩阵** `∂p/∂z`（一个 N×N 矩阵），再相乘。又慢又容易错。

但两步乘起来会化简成极其干净的结果：

```
∂L/∂z_i = p_i - 1{i == action}
```

也就是「**预测概率 − one-hot 标签**」。这就是为什么几乎所有分类网络都用
softmax + 交叉熵这一对组合：输出层的误差项直接就是"预测 − 真值"。

代码在 `loss.h: softmaxCrossEntropyGrad()`，自检程序的 `[4/6]` 项用数值微分验证了它。

> 这个公式是后面 REINFORCE 策略梯度的基石——策略梯度需要的
> `∂(-log π(a|s))/∂logits` 正好就是它。

## 第 5 章 · 反向传播 ★ 核心章节

### 5.1 问题是什么

我们想知道：**每个权重 `w` 稍微变大一点点，损失 `L` 会变大多少？**
也就是要算 `∂L/∂w`，对**所有**几千个权重都算一遍。

逐一用数值微分（扰动法）算？参数量 × 2 次前向传播，慢到不可用。
反向传播的价值就是：**一次前向 + 一次反向，同时算出所有参数的梯度。**

### 5.2 链式法则

以输出层的权重 `w_out[i][j]`（连接最后一个隐藏层第 i 个神经元和输出第 j 个）为例：

```
∂L/∂w_out[i][j] = ∂L/∂z_out[j] · ∂z_out[j]/∂w_out[i][j]
```

而 `z_out[j] = Σ_i a_hid[i]·w_out[i][j] + b_out[j]`，所以 `∂z_out[j]/∂w_out[i][j] = a_hid[i]`。
于是：

```
∂L/∂w_out[i][j] = delta_out[j] · a_hid[i]
```

用外积写就是 `dW_out = a_hid_last ⊗ delta_out`。**代码里就是这一行：**

```cpp
dw_out += outer(a_hid[NHID - 1], dLogits);
```

> `outer(u, v)` 就是 `u·vᵀ`，把两个向量变成矩阵，正好是权重矩阵的形状。

### 5.3 误差怎么往回流

现在算隐藏层。设 `delta` 表示「`∂L/∂z`」——**误差在某一层 pre-activation 上的表现**。

要从输出层回传到最后一个隐藏层，需要两步：

**第一步：把误差从 `z_out` 传回 `a_hid_last`**

```
∂L/∂a_hid_last[i] = Σ_j delta_out[j] · w_out[i][j]
```

注意这里是对 j 求和——`a_hid[i]` 会影响**所有**输出神经元。
写成矩阵就是 `W_out · delta_out`（注意不是 `Wᵀ`，因为我们的约定是行向量 `a·W`）。

**第二步：从 `a` 传回 `z`**

```
∂L/∂z_hid[i] = ∂L/∂a_hid[i] · dAF( z_hid[i] )
```

对每个分量分别是逐元素相乘（哈达玛积）。

合起来就是：

```cpp
vec<T, HW> delta = hadamard(w_out * dLogits, apply(dAF, z_hid[NHID - 1]));
```

> ⚠️ 这里 `apply(dAF, z_hid[...])` 传的是 **`z`**，不是 `a`。
> 如果你的 `dAF` 期望的是 `a`（像你原来的 `dsigmoid`），这一行就会静默算错。

### 5.4 完整循环

重复 `5.3` 的两步，一层层往回走：

```cpp
for (int i = NHID - 1; i >= 1; --i) {
    dw_hid[i - 1] += outer(a_hid[i - 1], delta);          // 这一层的权重梯度
    db_hid[i - 1] += delta;                               // 偏置梯度就是 delta 本身
    delta = hadamard(w_hid[i - 1] * delta, apply(dAF, z_hid[i - 1]));  // 继续往前传
}
dw_in += outer(a_in, delta);
db_in += delta;
```

**为什么偏置的梯度就是 `delta`？** 因为 `z = ... + b`，所以 `∂z/∂b = 1`，
链式法则下来 `∂L/∂b = ∂L/∂z · 1 = delta`。

### 5.5 四个公式汇总（背下来也不亏）

```
输出层权重：  dW_out  = a_hid_last ⊗ delta_out
输出层偏置：  db_out  = delta_out
隐藏层误差：  delta_h = ( W_next · delta_next ) ⊙ dAF( z_h )
隐藏层权重：  dW_h    = a_prev ⊗ delta_h
```

其中 `delta_out = ∂L/∂z_out` 由损失函数给出（MSE 是 `2(y-t)/N`，softmax+交叉熵是 `p - onehot`）。

### 5.6 为什么 `+=` 而不是 `=`

```cpp
dw_out += outer(...);      // 累加，不是覆盖
```

因为 `backward()` 被设计成**累加**语义：一次更新可以先把一个小批量的多条样本
依次 `backward()`，梯度自动叠加，最后统一 `step()`。

代价是你必须记得两件事（都是新手必踩的坑）：

1. 每个 batch 开始前调用 `zeroGrad()`
2. 累加完 N 条之后调用 `scaleGrad(1.0/N)` 变成平均梯度

**第 2 条尤其容易忘。** 忘了它，等效学习率就被放大 N 倍。
本教程的配套自检程序第一次跑就栽在这上面：sin 拟合直接发散成 `nan`。

## 第 6 章 · 梯度下降与优化器

### 6.1 最朴素的 SGD

```
w ← w - lr · ∂L/∂w
```

- 梯度指向"损失上升最快的方向"，所以要**减去**它
- `lr`（学习率）控制每一步走多远

### 6.2 学习率是最重要的超参数

| 现象 | 诊断 |
|------|------|
| 损失变成 `nan` / `inf` | 学习率**太大**，更新步子跨过了谷底并越走越远 |
| 损失来回震荡不下降 | 学习率偏大 |
| 损失下降极慢 | 学习率**太小** |
| 损失降一段后长期不动 | 学习率可能太小，或结构容量不够 |

调参基本法：先取 `1e-2` 试，`nan` 了就除以 10，太慢就乘 3。

### 6.3 动量（Momentum）

```
v ← momentum · v - lr · ∂L/∂w
w ← w + v
```

把历史梯度累积成一个"速度"。好处：

- **方向一致的维度越走越快** → 加速收敛
- **来回震荡的维度互相抵消** → 抑制抖动

典型取值 `0.9`。注意动量会把等效学习率放大最多 `1/(1-momentum)` 倍
（`momentum=0.9` 时是 10 倍），所以开了动量往往要相应调小 `lr`。

代码在 `network.h: step(lr, momentum)`，`momentum` 默认 `0` 即纯 SGD。

### ★ 6.4 累加梯度 vs 平均梯度

这是本项目自检程序真实踩过的坑，值得单独讲：

```cpp
// 错误写法：等效学习率被放大 N 倍
net.zeroGrad();
for (每条样本) net.backward(...);     // 梯度累加成"和"
net.step(0.02, 0.9);                   // ← 直接更新，配上动量必然发散

// 正确写法
net.zeroGrad();
for (每条样本) net.backward(...);
net.scaleGrad(1.0 / N);                // ★ 变成"平均"
net.step(0.02, 0.5);
```

**batch size 变了，等效学习率也会变**——这也是为什么换 batch size 时通常要重新调 `lr`。

## 第 7 章 · 权重初始化

### 7.1 为什么不能全部初始化为 0

如果一层里所有神经元的权重完全相同，那么它们的输出、梯度、更新也完全相同。
**它们会永远保持一模一样，等于只有一个神经元。**
这叫对称性问题，所以权重必须随机初始化。

### 7.2 随机就行了吗？—— 你原来写法的致命问题

你的原稿用的是 `U(0,1)`（0 到 1 的均匀分布）。两个毛病：

**毛病一：全是正数。** 一层里 16 个输入全是正的，加权和 `z = Σ a_i·w_i` 也是正的，
而且均值被抬高到 `0.5 × fan_in`。tanh 立刻饱和。

**毛病二：方差固定，不随 fan_in 缩放。** `U(0,1)` 的方差恒为 `1/12`。
一层 `fan_in` 个独立项相加，方差变成 `fan_in/12`，标准差变成 `√fan_in/√12`。
层数一多，信号要么指数级爆炸要么指数级衰减。

**这不是理论担忧，是能直接测出来的。** 自检程序 `[6/6]` 项的输出：

```
  隐藏层        U(0,1)        Xavier
    1         1.210e-01     1.516e-01
    2         2.793e-02     1.885e-01
    3         7.084e-05     1.595e-01
    4         9.488e-06     1.466e-01
```

`U(0,1)` 初始化下，信号传到第 3 层就衰减了 **4 个数量级**——神经元全部饱和，
`dtanh ≈ 0`，梯度回不来，网络根本学不动。Xavier 则稳定在 0.15 左右。

训练速度的差距（同样 600 轮、同样学习率）：

| 初始化 | 训练前 MSE | 训练后 MSE |
|--------|-----------|-----------|
| `U(0,1)` | 44.35 | 0.0997 |
| Xavier | 0.316 | **0.0161** |

### 7.3 Xavier / He：让方差穿过层时保持不变

思路很直接：**希望每一层输出的方差 ≈ 输入的方差**。

一层做的是 `z_j = Σ_i a_i·w_ij`。若 `a_i` 方差为 `σ_a²`、`w_ij` 方差为 `σ_w²`，
且独立同分布，则

```
Var(z_j) = fan_in · σ_a² · σ_w²
```

要让它等于 `σ_a²`，就得 `σ_w² = 1/fan_in`，即 **`σ_w = 1/√fan_in`**。

- **Xavier/Glorot**（适合 tanh/sigmoid）：兼顾前向和反向，取
  `U(-√(6/(fan_in+fan_out)), +√(6/(fan_in+fan_out)))`
- **He**（适合 ReLU）：ReLU 会把一半神经元置零，方差减半，所以要补回来，
  取 `N(0, √(2/fan_in))`

代码在 `network.h: init()`，通过 `Init::He` / `Init::Xavier` 选择。

### 7.4 偏置初始化为 0

打破对称性靠的是**权重**的随机性，偏置没必要随机。从 0 出发更稳定。
（你原来的写法给偏置也做了随机初始化，虽不致命但没必要。）

## 第 8 章 · 怎么证明自己写对了：数值梯度检查

### 8.1 为什么"能收敛"不等于"写对了"

训练能收敛只能说明**大方向没错**。如果某个符号搞反了、某个 `z` 传成了 `a`、
某个转置漏了，网络可能依然会缓慢地学一点，甚至碰巧也能收敛——这种 bug 最难查。

### 8.2 中心差分：最笨但绝对可靠的办法

导数的定义就是极限：

```
∂L/∂w ≈ [ L(w + ε) - L(w - ε) ] / (2ε)
```

用**中心差分**而不是前向差分 `[L(w+ε) - L(w)]/ε`，因为中心差分的误差是 `O(ε²)`
而不是 `O(ε)`，精度高得多。取 `ε = 1e-5` 时误差大约在 `1e-10` 量级。

实现只要三步（`tools/nn_selftest.cpp: gradientCheck()`）：

1. 反向传播算出解析梯度
2. 对每个参数：`w+ε` 前向算一次损失，`w-ε` 前向算一次损失，求差分
3. 逐个比对

### 8.3 判据

用**相对误差**，分母取 `|数值| + |解析|` 以避免接近 0 时误差被放大：

```cpp
double rel = std::abs(numeric - analytic) / std::max(1e-8, std::abs(numeric) + std::abs(analytic));
```

判据取 `rel < 1e-6`。双精度下中心差分的极限大约就是 `1e-9 ~ 1e-10`，
所以低于 `1e-6` 才叫"通过"。

**本项目的实测结果：抽查 62/62 个参数，最大相对误差 `9.06e-10`。**

### 8.4 以后每次改反向传播，都跑一次它

这是你未来的"单元测试"。改完 `backward()` 就跑 `nn_selftest.exe`，
`[1/6]` 项过了才说明梯度是对的。

## 第 9 章 · 常见训练失败模式速查

| 症状 | 最可能的原因 | 排查方向 |
|------|-------------|---------|
| 损失 `nan` / `inf` | 学习率太大；忘了 `scaleGrad(1/N)` | 除以 10 重试；检查梯度平均 |
| 损失完全不降 | 学习率太小；初始化不对；忘记 `zeroGrad()` | 打印梯度范数；换 Xavier/He |
| 损失降一点就卡住 | 激活函数饱和（`dAF(z) ≈ 0`）；容量不足 | 看第 7 章的信号统计；换 ReLU 或加宽 |
| 训练集好、新数据差 | 过拟合 | 加数据 / 减小网络 / 加正则 |
| 输出全是同一个值 | 权重初始化成全 0；对称性没打破 | 检查 `init()` |
| 梯度检查不通过 | 反向传播写错 | 单独检查某一层的 `delta` |

## 第 10 章 · 下一站：从 MLP 到策略网络

到这里，你已经有了一个**能学**的 MLP。但 MLP 本身不知道"该学什么"——
损失函数是人类给它的（"模仿这个标签"）。

强化学习的核心问题是：**没有标签，只有奖励，怎么办？**

贪吃蛇里，蛇吃到食物 +1 分、撞死 −1 分，但一个动作的后果可能要几百帧之后才显现。
这就是**延迟奖励**和**信用分配**问题。

下一阶段要做的 **REINFORCE（策略梯度）** 回答的就是这个问题：

1. 网络输出 logits → softmax → 策略 `π(a|s)`
2. 按策略采样一个动作
3. 一整局结束后，用总回报 `G` 给这一局里每个动作的 `-log π(a|s)` 加权
4. 用 `softmaxCrossEntropyGrad()` 得到 `∂L/∂z_out = p - onehot`，再乘上 `G`，喂给 `backward()`

**第 4 章学的那个化简公式 `p - onehot` 就是在这里发挥作用的**——
策略梯度的梯度形式，和分类问题的交叉熵梯度是同一个东西，只差一个权重 `G`。

具体设计见 `docs/20-游戏训练接口设计.md`。
