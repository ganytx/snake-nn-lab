# 项目总览 — snake-nn-lab

> **当前状态以 [docs/30-开发计划与进度.md](30-开发计划与进度.md) 为准**（本文只讲"是什么、怎么跑"）。

## 这个项目要做什么

**用神经网络训练出会玩贪吃蛇的 AI。**

贪吃蛇游戏本身只是**载体**——它的真正身份是一个**强化学习环境**：
提供观测、接受动作、返回奖励。

```
┌──────────────────────────────────────────────────────────────┐
│                        snake-nn-lab                          │
│                                                              │
│   ┌──────────────────┐          ┌──────────────────────┐    │
│   │  游戏 / 训练场地  │  感知    │  算法（Brain）        │    │
│   │  src/scenes/     │ ───────► │  src/brain/          │    │
│   │  src/agent/      │          │   RuleBrain  规则AI   │    │
```

## 技术选型

| 项目 | 选择 | 原因 |
|------|------|------|
| 语言 | C++17 | 与游戏一致，训练无需跨进程通信 |
| 图形 | SFML 2.6.2 | 看 AI 表现时用；训练时完全关闭 |
| 构建 | CMake + MinGW-w64 | 沿用原有工具链 |
| 神经网络 | 自己实现（`src/nn/`） | 教学目的 |
| 学习算法 | REINFORCE（策略梯度） | 从延迟奖励中学习，无需标签 |

> 为什么不直接用 PyTorch？因为本项目的目标之一是**彻底搞懂神经网络**。
> 写一遍反向传播之后，再去看 `loss.backward()` 会有完全不同的理解。
> 关于"要不要换 Python"的取舍分析，见 `docs/50-训练链路.md` 末节与开发日志。

## 五个构建目标

| 目标 | 类型 | 用途 |
|------|------|------|
| `snake_game.exe` | 图形 | 游戏本体（主菜单：开始游戏 / **训练模式** / 训练数据 / 设置 / 退出） |
| `nn_selftest.exe` | 控制台 | MLP 自检 6 项（改 `src/nn/` 后必跑） |
| `bench_sim.exe` | 控制台 | 仿真性能探针 + 标墙对拍 |
| `train_probe.exe` | 控制台 | REINFORCE 训练（命令行入口，写 `train_metrics.csv`） |
| `replay_check.exe` | 控制台 | ★ 世界指纹回归（改世界推进后必跑） |

```
双击 build.bat   → 编译全部
双击 run.bat     → 运行游戏
```

> 四个控制台程序**必须在 `build\` 目录下运行**
> （权重写在当前目录，训练存档写在 `build\saves\`）。

## 游戏怎么玩

| 操作 | 键位 |
|------|------|
| 转向 | 鼠标移动（360°）；←/→ 为备选 |
| 加速 | 空格 / 鼠标左键 |
| 暂停 | ESC |
| 调试面板 | F3 |
| 重开一局 | R |
| 死后观战 | 自动进入；方向键漫游、PgUp/PgDn 缩放 |

**流程**：主菜单 →（开始游戏）→ **对局设置** →（回车，全部有默认值）→ 对局。

对局设置里可以调：分成几队、每队几条蛇、你在哪一队、限时、
以及**每队用什么算法**（从 `BrainRegistry` 动态读取，
所以注册了新算法这里自动就能选到）。

## 想看训练成果

### 方式一：看它实时训练（推荐先用这个）

**主菜单 →「训练模式」** —— 在游戏进程里**真的训练**，能亲眼看着它一步步学。

先过「训练设置」界面选任务（三种，见 [docs/80](80-训练可视化.md)），
然后 Enter 开始。面板上会显示**奖励构成**和**策略概率** ——
调参时这两栏是唯一有用的东西。

操作：`Enter` 暂停 / `V` 关渲染加速 / `[` `]` 调速度 / `S` 保存权重 / `L` 加载存档 /
`ESC` 返回。

### 方式二：把训练好的权重接进对局

1. `build.bat` → `run.bat`
2. 主菜单 →「开始游戏」→ 对局设置
3. 把某一队的算法切到 **「神经网络 (已加载权重)」**（留一队规则 AI 做对照）
4. 回车开打

> ⚠️ 权重从 `weights/policy.txt` 或 `build/train_probe_weights.txt` 读。
> 名称里会**如实标注**是"已加载权重"还是"未找到权重, 随机" —— 一眼能看出有没有加载上。

### 方式三：看跑完的曲线

命令行跑 `build\train_probe.exe`（写 `train_metrics.csv`），
然后主菜单 →「训练数据」画曲线。
